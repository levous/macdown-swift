# Open in MacDown

A VS Code extension that opens the current Markdown file in MacDown: from the
Command Palette (**MacDown: Open in MacDown**), the editor's title bar, the
editor and Explorer context menus, and ⌥⌘M. Unsaved changes are saved first,
since MacDown reads the file from disk.

See [docs/VS-CODE.md](../../docs/VS-CODE.md) for installing it.
